## Теоретическая справка

### Что такое алгоритм?
**Алгоритм** — это точная конечная последовательность действий, направленная на достижение определённой цели или решение конкретной задачи.

### Свойства алгоритма
1. **Дискретность** — алгоритм расчленяется на отдельные завершенные шаги (действия).
2. **Детерминированность (определенность)** — каждый шаг алгоритма должен быть однозначным и понятным, исключающим двусмысленность.
3. **Конечность** — выполнение алгоритма должно приводить к результату за конечное число шагов.
4. **Массовость** — алгоритм должен быть применим для целого класса однотипных задач с различными исходными данными.
5. **Результативность** — алгоритм всегда должен завершаться получением конкретного результата (или сообщением об ошибке при некорректных данных).

## Как составляются блок-схемы
Блок-схема — это графическое представление алгоритма, где каждый этап отображается в виде геометрической фигуры (блока), а связи между ними указываются стрелками, задающими направление выполнения.

### Основные элементы блок-схем:
* **Овал (Начало/Конец):** Обозначает точку старта и точку завершения алгоритма.
* **Прямоугольник (Процесс):** Используется для выполнения любых математических вычислений, операций присваивания или действий.
* **Ромб (Решение/Условие):** Содержит вопрос или логическое условие, предполагающее два варианта ответа («Да» или «Нет»), организуя ветвление алгоритма.
* **Параллелограмм (Ввод/Вывод):** Отвечает за ввод данных пользователем или вывод результатов на экран.
* **Линии со стрелками:** Показывают последовательность и направление выполнения шагов.
